## Migratory

Simple migrations tool for python projects that use PostgreSQL.


### Inspiration

I needed a solution that would allow me to run database migrations for my bot. I made a simple version of it, but never took it any further. This project is designed to take that concept and go further with it. I hope to be able to support other DB engines, such as MySQL.


### To create migrations

Use `migratory new` to create a new migration.
